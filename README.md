# KR Earnings Pulse

국내 주요 종목의 영업(잠정)실적 공시를 DART에서 감지해 텔레그램으로 즉시
알리는 봇입니다. 평일 07:00~20:00 KST에 5분 간격으로 확인합니다.

- 감시 종목: `watchlist.json` (종목 추가/삭제는 이 파일 수정)
- 공시 원문에서 매출액·영업이익·전년동기 증감률을 자동 추출 (실패 시 링크만 발송)
- 상태(발송 이력)는 Actions 캐시로 관리해 중복 발송을 막습니다

## 로컬 테스트

```
DART_API_KEY=... python earnings_pulse.py --dry-run --date 20260707
```

개인 투자 참고용이며 수치는 공시 원문 확인을 권장합니다.
